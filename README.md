# HOUR LAB v1.0

農作業の時間、機械のアワメーターと料金を記録するiPhone向けPWAです。

## 現場で使う

1. 「設定」で機械の時間単価と、全機械共通のオペレーター単価を保存します。空欄の単価は未設定として扱います。
2. 「新規作成」で開始時刻を取得します。作業先と開始アワメーターを入力し、時刻は取得値や15分単位の候補から選びます。
3. 「終了」で終了時刻を取得し、終了アワメーターを入力して「保存」します。
4. 再開する場合は「続きから」を使います。日をまたぐ作業は日別に記録します。
5. 紙に転記する日は「作業日誌一覧」で対象年・月を選び、前へ・次へで順に表示します。

時刻の手入力は分単位です。料金は入力された分数を使い、機械使用料とオペレーター料をそれぞれ円単位で四捨五入してから合算します。単価は日誌の初回保存時に固定します。未設定の単価は対象日誌の編集画面で補えます。

Safariの共有メニューから「ホーム画面に追加」できます。初回読み込み後はオフラインでも入力できます。端末のサイトデータを消去すると、同期前の記録や端末設定も消えます。

## Googleスプレッドシートに接続する

1. 同期先として用意したスプレッドシートを所有者のGoogleアカウントで開きます。新規スプレッドシートにも導入できます。
2. 「拡張機能 → Apps Script」を開き、`Code.gs` の内容を貼り付け、保存します。
3. 関数 `setup` を一度実行し、Googleの権限を承認します。日誌・作業明細・同期台帳の各タブが作成されます。
4. Apps Scriptのプロジェクト設定で、スクリプト プロパティ `HOUR_LAB_KEY` を確認します。キーはチャットや公開リポジトリへ貼り付けず、HOUR LABの設定画面に直接入力してください。
5. 「デプロイ → 新しいデプロイ → ウェブアプリ」を選びます。実行ユーザーに自分、アクセスできるユーザーに「全員」を指定します。エンドポイントでは接続キーを照合します。シートの共有設定は変更不要です。
6. デプロイで発行される `/exec` URLとキーをHOUR LABの「設定」に保存し、「スプシに保存」を押します。
7. 日誌と作業明細の両タブを確認します。同じデータで再実行した場合、日誌IDで照合し、行を重複作成しません。

編集はHOUR LABで行います。日誌・作業明細は同期台帳から再生成されます。競合時は端末の変更を保持し、設定で両端末の内容を確認できます。スプレッドシート側を採用するか、その内容を採用後に必要な編集をやり直せます。

## 開発

`python3 -m http.server 8000` で起動し、http://localhost:8000/ を開きます。GitHub Pagesでは main ブランチのルートを公開します。

`node --test tests/*.test.cjs` で計算・同期ロジックをテストできます。
